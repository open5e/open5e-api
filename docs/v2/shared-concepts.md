# Shared concepts

In the current implementation, certain concepts are so universal that we have decided to have them be considered "core", as they are basic world concepts with basically the same definition between. Exceptions that arise can be implemented within the individual document.

These concepts include:
- Ability (e.g. Strength)
- Alignment (e.g. Chaotic Good)
- Creature Type (e.g. Abberation)
- Damage Types (e.g. Acid)
- Environment (e.g. Mountains)
- ItemCategory (e.g. Scroll)
- ItemRarity (e.g. Uncommon)
- Language (e.g. Dwarvish)
- Size (e.g. Large)
- Skill (e.g. Animal Handling)
- Spell School (e.g. Illusion)
